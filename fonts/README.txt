KaiTi.woff
  A character subset of KaiTi (c) Beijing ZhongYi Electronics Co. This is a commercial typeface that
  ships with Windows; it is not open source. The page uses the copy installed on the device first and
  only downloads this file where KaiTi is missing (for example iPad / iPhone). If you would rather not
  publish it, delete this file: Chinese text then falls back to the open-source LXGW WenKai.
